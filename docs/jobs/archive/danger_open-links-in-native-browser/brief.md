## What

Links from the solyto desktop app open in a very minimalistic browser UI.
Since the solyto desktop app runs on a desktop that most certainly has an actual browser, I'd prefer it for links from solyto (e.g. link library) to open in the actual default browser of the user.
Otherwise, if you open a link in the native UI, you can't see downloads, etc.
